My teaching focuses on print-production systems, process control, and digital-printing workflows, with emphasis on measurement, applied tools, and laboratory-based learning.

Printing Process Control

This course examines process and quality control in offset lithography, treating prepress, plate making, and printing as an integrated production workflow.

Main topics

  • Process and quality control in offset lithography
  • Colour perception and reproduction
  • Plate-making procedures and press operation
  • Standards and specifications for process control
  • Print-quality measurement and technical reporting

Applied learning tools

  • Monitor-colour verification using X-Rite i1Profiler
  • Colour measurement using X-Rite i1 Pro
  • Digital-proof verification using Fogra MediaWedge CMYK V3
  • Solid Ink Density (SID) analysis
  • Tone Value Increase (TVI) analysis
  • Print contrast and ink-trapping analysis

PrintQC Lab

PrintQC Lab is an open learning toolkit supporting practical exploration of print-quality measurement, process control, colour validation, and laboratory scenarios.

Digital & Variable Data Printing

This course introduces digital-printing technologies, variable-data printing, print-on-demand production, web-to-print processes, and data management for contemporary print-production environments.

Main topics

  • Digital-printing technologies and applications
  • Variable-data and print-on-demand production
  • Web-to-print and digital-production workflows
  • Data-driven print processes
  • Data scrubbing and cleansing
